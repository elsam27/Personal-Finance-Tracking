# Personal-Finance-Tracking

This is a Python-based personal finance tracking program that allows its users to manage their income, expenses, and saving goals all in the same place!

## Features

- Add and track income and expenses
- Set saving goals and track progress
- Create monthly/weekly budgets
- Modify and/or delete transactions
- Export data to CSV and text reports
- Data persistence with JSON storage

## Requirements
- Python 3.6+
